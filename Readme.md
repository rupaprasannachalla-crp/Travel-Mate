# TravelMate 🚆✈️🚌

## Smart Travel Booking Web Application

TravelMate is a responsive travel booking web application developed using **HTML, CSS, JavaScript, and Supabase**. It allows users to book trips, view booking history, generate digital travel tickets, and securely store booking details in a cloud database.

## Features

* 🏠 Simple and responsive home page
* 📝 Travel booking form
* 👤 Passenger details collection
* 🚌 Multiple travel modes

  * Bus
  * Cab
  * Train
  * Metro
* 📅 Trip date selection
* 💳 Payment method selection

  * Credit Card
  * Debit Card
  * UPI
* 📊 Booking summary before payment
* 💰 Estimated travel cost calculation
* 🛡️ Basic travel safety prediction
* 🎫 Digital ticket generation
* 📚 My Bookings page
* 👤 User profile page
* ☁️ Cloud database integration using Supabase

## How It Works

1. Open the TravelMate application.
2. Navigate to the **Booking** page.
3. Enter passenger and trip details.
4. Select travel mode and payment method.
5. View the booking summary.
6. Proceed to payment.
7. Confirm payment.
8. A digital ticket is generated.
9. Booking details are stored in the Supabase database.
10. View previous bookings in the **My Bookings** section.

## Database

The application uses **Supabase** as the backend database to store:

* Name
* Email
* Source
* Destination
* Number of companions
* Travel mode
* Trip date
* Payment method
* Payment status
* Safety prediction
* Estimated distance
* Estimated duration
* Estimated travel cost
